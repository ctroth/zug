# Zug File Organizer

In development...

## Description

Zug File Organizer is a very basic file organizer python program that is used via the CLI.  

You are able to -

- view all of the files in the currenty directory
- list all of the subdirectories
- list all files based on their type
- change the directory you are in
- organize files by type into pre-defined folders
- delete all files by their file type, 
- delete specific files
- move specific files
- automate the entire process
